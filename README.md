# キャンセル・お断り連絡文メーカー

予約のキャンセルやお断りの連絡文を、場面と理由を選ぶだけで下書きするWebページです（100日100プロダクト Day059）。

- 場面: こちらの都合でキャンセル／満席でお断り／体調不良でお休み／天候・災害で中止／お客様のキャンセルへの返信／日程変更のお願い
- 理由・日時・お名前・店名・代わりの案内を入れると、LINE・メール・DM向けの文面が出ます。メールは件名つき。コピーは1タップ
- 入力は端末のブラウザの中だけで処理し、保存しません（アクセス解析の閲覧数計測のみ）
- AI・外部APIは使っていません。決まった言い回しに入力を差し込んで作ります

## 限界
- 文面はあくまで下書きです。キャンセル料の金額・法的な有効性・規約との関係は判断しません
- 未入力の箇所は黄色の〔 〕で残り、警告が出ます。送る前に直してください
- iPhone・Androidの実機でのコピー動作は未確認です

## 検算
`node source/run-checks.js`（全594通りの組合せで禁止語・未入力警告・件名・敬称・金額の変換を確認）
